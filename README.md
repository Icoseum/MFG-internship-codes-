 Overview of the MATLAB codes

The MATLAB codes in this repository were developed as part of a master's internship.

The reference implementation is mfg_toumi2024. It was first improved, leading to mfg_anderson. The main contributions presented in the report were subsequently implemented in the following three codes: mfg_heteregeneous, mfg_upgrade1_congestion, and mfg_upgrade2_congestion.

The code mfg_bcs_variational implements the algorithm proposed by BCS.

Finally, mfg_upgrade1_congestion_max and mfg_upgrade2_congestion_max extend the two corresponding variants to configurations deliberately designed to exhibit very high levels of congestion.

Upon execution, each MATLAB code generates a data file that can be used to create an animation with the Python script animation_mfg.py.
